## 🧚‍♀️ How to Run It Locally

```bash
# clone the repo
git clone https://github.com/SanyaShresta25/Personal-Portfolio.git

# go into the folder
cd Personal-Portfolio

# install dependencies
npm install

# run the dev server
npm run dev
```
